## Contenido del repositorio

- `cava-ambar/` — sitio web (HTML5 semántico + una hoja de estilos CSS externa + un archivo de JavaScript, sin frameworks).
- `documentacion/` — carpetas técnicas en Word: planificación de la Fase 1, y maquetación con CSS e interactividad con JavaScript de las Fases 2 y 3.
- `presentacion/` — presentación con los mockups/wireframes de las páginas del sitio.

## Sobre el sitio

Cava Ámbar es una tienda ficticia de bebidas alcohólicas (whisky, gin, vodka, tequila, ron, mezcal, champagne y licores). El sitio tiene tres páginas principales (Inicio, Catálogo y servicios, Contacto) más las páginas individuales de cada producto. Tiene estructura semántica en HTML5, maquetación responsiva con Flexbox en CSS y un menú mobile, validación de formulario y buscador de catálogo con JavaScript.
