## Contenido del repositorio

- `cava-ambar/` — sitio web estático (HTML5 semántico + una hoja de estilos CSS externa, sin frameworks ni JavaScript).
- `documentacion/` — carpeta técnica en Word con la planificación de la Fase 1.
- `presentacion/` — presentación con los mockups/wireframes de las páginas del sitio.

## Sobre el sitio

Cava Ámbar es una tienda ficticia de bebidas alcohólicas (whisky, gin, vodka, tequila, ron, mezcal, champagne y licores). El sitio tiene tres páginas principales (Inicio, Catálogo y servicios, Contacto) más las páginas individuales de cada producto.
